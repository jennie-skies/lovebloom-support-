# KindHeart website preview

A responsive, static first version of KindHeart.

## Try it
Open `index.html` in a browser. It includes encouragement messages, draft service prices, and a demo advice-request form.

## Important limits
- The form does not send or store submissions.
- No email or payment provider is connected.
- Do not collect real customer details until a secure backend, privacy notice, and adult-supported operations are in place.
- Prices are draft examples only.

## Publish a public preview with GitHub Pages
1. A trusted adult can help create/use a GitHub account and a **public** repository named `kindheart-preview`.
2. Upload `index.html` to the top level of the repository.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for deployment and use the URL shown in Settings → Pages.

A GitHub Pages site is public on the internet. Keep this repository free of personal information, private keys, customer messages, and secrets. A static site cannot securely process payments or handle private form submissions by itself.
